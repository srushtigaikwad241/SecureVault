SECURITY AWARENESS

Mobile & Wireless Security

Protect mobile devices, wireless connections, personal information and sensitive data from common cybersecurity threats.

01

Why Mobile Security Matters

Mobile devices store personal and sensitive information and frequently connect to wireless networks. Weak security can expose this data to unauthorized access.

02

Common Mobile & Wireless Threats

Understand the major security risks associated with mobile devices and wireless communication.

📶
THREAT 01

Insecure Wi-Fi

Unsecured wireless networks may expose sensitive information and increase the risk of unauthorized network access.

Protection Use trusted and password-protected wireless networks.
🎣
THREAT 02

Mobile Phishing

Attackers may send fake messages, emails or websites designed to trick users into revealing sensitive information.

Protection Verify links and never share passwords or security codes through suspicious messages.
📲
THREAT 03

Malicious Applications

Applications from untrusted sources may contain malicious software or request unnecessary permissions.

Protection Install applications from trusted sources and review permissions.
🔒
THREAT 04

Device Theft or Loss

A lost or stolen mobile device can expose personal information and sensitive files.

Protection Use a strong screen lock and maintain secure backups.
📡
THREAT 05

Bluetooth Risks

Improperly configured Bluetooth connections can create unnecessary security exposure.

Protection Keep Bluetooth disabled when it is not required and use trusted connections.
👤
THREAT 06

Social Engineering

Attackers may manipulate users into sharing passwords, verification codes or sensitive information.

Protection Verify requests before sharing sensitive information.
03

Mobile Security Checklist

Follow these basic security practices to protect your mobile device and information.

✓

Strong Screen Lock

Use a strong PIN, password or supported biometric authentication.

✓

Keep Software Updated

Install security and operating system updates regularly.

✓

Trusted Applications

Install applications only from trusted sources.

✓

Review Permissions

Check what permissions applications request before granting access.

✓

Avoid Suspicious Links

Do not open unexpected links or attachments from unknown sources.

✓

Secure Wireless Networks

Prefer trusted networks and avoid sharing sensitive information over unknown networks.

✓

Backup Important Data

Maintain secure backups of important files and information.

✓

Report Suspicious Activity

Report unusual or suspicious security activity through the appropriate channel.
